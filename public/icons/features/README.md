# Feature icons

Selected Phosphor Icons duotone SVGs, from `@phosphor-icons/core` version 2.1.1.

- Upstream: https://github.com/phosphor-icons/core
- Source CDN: https://cdn.jsdelivr.net/npm/@phosphor-icons/core@2.1.1/assets/duotone/
- License: MIT; copyright (c) 2023 Phosphor Icons. The complete notice is in LICENSE.txt.
- Modification: `currentColor` is replaced with a coordinated foreground color. The original 20% opacity background layer and all path geometry are preserved.

These selected assets are served locally by the static site. Icon mappings and colors are recorded in `src/lib/feature-icons.json`.
